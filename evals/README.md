# DPL evaluations

This directory is reserved for reproducible public evaluation cases.

DPL will not manufacture showcase cases merely to increase the count. Add a case only when its product philosophy, prompt, snapshot, expected checks, and allowed scope can be published safely and reproduced.

When enough cases exist, compare at least:

1. no design skill;
2. current DPL;
3. DPL with structured evidence/verdict tooling.

Useful metrics include philosophy-check pass rate, scope violations, verdict overclaim rate, false engine-use claims, and run/turn cost.

Synthetic cases may test the verifier itself, but must not be presented as evidence that DPL improves a real product.
